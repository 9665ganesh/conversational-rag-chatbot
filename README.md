# Conversational RAG Chatbot

A Conversational Retrieval-Augmented Generation (RAG) chatbot built using:

- LangChain
- ChromaDB
- HuggingFace Embeddings
- Groq (Llama 3.3 70B)

## Features


- Semantic Search
- Conversational Memory
- Query Rewriting
- Chroma Vector Database
- HuggingFace Embeddings
- Groq LLM

## Future Improvements

- PDF Support
- Source Citations
- Streamlit UI
- Multi-file Upload
